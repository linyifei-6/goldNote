# GoldNote 1.0.0

GoldNote 是一个微信小程序，定位为双模块生活记录工具：一部分服务于黄金交易记录、收益分析与历史统计，另一部分服务于婚礼筹备、预算、任务和亲友协同。1.0.0 版本已经完成核心业务闭环、视觉统一、主要交互收敛以及云开发同步能力。

详细发布说明见 [RELEASE_NOTES_1.0.0.md](RELEASE_NOTES_1.0.0.md)。

## 版本定位

- 当前版本：`1.0.0`
- 产品形态：微信小程序
- 数据模式：本地存储 + 微信云开发双通道
- 账号体系：微信授权登录，OpenID 作为唯一身份标识

## 1.0.0 功能总览

### 黄金笔记

- 持仓总览
	- 显示总持仓、成本均价、持仓收益、累计已实现收益、收益率、总投入、持仓市值。
	- 分平台展示持仓、平台均价、累计收益、持有收益。
	- 平台顺序固定为民生、浙商、招商、其他。

- 实时金价
	- 支持智能模拟与手动输入两种金价模式。
	- 支持智能模拟金价。
	- 支持模拟开始 / 暂停。
	- 支持手动输入价格切换。

- 收益曲线
	- 按天聚合展示累计收益。
	- 支持按平台、按时间范围查看。
	- 支持主图查看与趋势视图大图弹层。
	- 大图支持时间窗口切换：30天、90天、180天、全部。

- 交易录入
	- 支持买入、卖出。
	- 实时预览手续费、净额、金额。
	- 平台统一为民生、招商、浙商、其他。
	- 招商卖出免手续费，其他平台默认 0.4%。

- 历史页
	- 综合筛选：时间、交易、平台、类型四列统一布局。
	- 查询统计与记录总览已合并为单页。
	- 支持快捷查询：今日、昨日、本周、上周、本月、最近10次买入、最近10次交易。
	- 支持自定义起止日期查询。
	- 支持查看本次查询命中的交易记录。
	- 支持在历史页直接修改 / 删除记录。
	- 支持从交易总览中选定多条记录并计算选定记录统计。

- 数据管理
	- 支持清空当前账号全部黄金交易数据。
	- 清空逻辑兼容云端未升级场景，会自动降级为逐条删除。

### 结婚笔记

- 婚礼主页
	- 顶部账号栏与黄金页统一。
	- 基础信息包含婚礼日期、地点、预算。
	- 支持编辑时保留草稿，避免定位返回后被覆盖。

- 备婚任务
	- 支持任务新增、编辑、删除、恢复、排序。
	- 优先级采用星级点选而非滑轮选择。
	- 任务类型、排序方式均已按钮化。

- 预算与支出
	- 支持预算录入与支出记录。
	- 在婚礼流程中配合任务进度一起展示。

- 亲友邀请
	- 支持邀请链接码、邀请留言、亲友状态管理。
	- 支持亲友确认出席。

- 数据管理
	- 支持清除当前账号全部备婚数据。

### 账号与场景入口

- 登录页支持微信授权登录。
- 场景页支持账号资料展示、昵称编辑、本地头像选择上传。
- 已移除不稳定的“使用微信头像 / 微信昵称快捷项”。

### 好友机制（一期/二期）

- 新增好友中心：支持黄金好友、情侣关系、亲友关系的申请与处理。
- 黄金好友：可切换查看对方持仓/历史，好友视图为只读模式。
- 情侣关系：婚礼任务、预算、邀请信息共享同一份数据。
- 亲友关系：可查看婚期并在祝福墙留言。
- 详细实现文档见 [SOCIAL_REQUIREMENTS_PHASE1_PHASE2.md](SOCIAL_REQUIREMENTS_PHASE1_PHASE2.md)。

## 核心业务规则

### 黄金收益口径

- 累计收益：仅统计已实现收益，不随实时金价浮动。
- 持仓收益：按当前金价与持仓成本差额计算浮动收益。
- 卖出收益：优先使用 `net_amount / weight` 推导实际卖出单价。
- 平台归并：旧平台名称统一归并到民生、招商、浙商、其他。

### 交易规则

- 买入净额记为负数，表示资金流出。
- 卖出净额记为扣除手续费后的实际到账金额。
- 删除、更新交易后会重新同步并校验历史持仓序列。

### 婚礼数据规则

- 婚礼主页基础信息会优先保护本地编辑草稿。
- 任务优先级范围为 1 至 5 星。
- 亲友邀请使用邀请码与当前登录用户进行关联。

## 本地运行

1. 使用微信开发者工具导入项目根目录。
2. 在微信开发者工具中配置自己的 AppID，测试可使用测试号。
3. 根据你的云开发环境修改 [app.js](app.js) 中的 `env`。
4. 如需启用云能力，先在微信开发者工具中开通云开发环境，并部署 `cloudfunctions` 目录。
